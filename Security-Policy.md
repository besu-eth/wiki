# Security Policy

This page describes how to report a security bug in Besu and who receives those reports.

## Reporting a security bug

If you think you have discovered a security issue in Besu, please report it by messaging the 
dedicated security list: [`security-besu@lists.hyperledger.org`](mailto:security-besu@lists.hyperledger.org).
We take all security bugs seriously.
If a report is confirmed upon investigation, we patch it within a reasonable amount of time and 
release a public security bulletin discussing the impact and crediting the discoverer.

In your report, include a description of the flaw and any related information, such as reproduction 
steps, the affected version, and whether the flaw is known to be actively exploited.

Don't open a public GitHub issue for a security bug.

For how Besu prioritizes defects, see the [Defect Prioritization Guide](Defect-Prioritization-Guide).
