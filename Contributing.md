Besu welcomes contributions in many forms: code, documentation, raising issues, and helping others in chat.

## Start here

Everything you need to decide whether and how to contribute lives in the **[Contributing guide (`CONTRIBUTING.md`)](https://github.com/besu-eth/besu/blob/main/CONTRIBUTING.md)** in the main repository. It covers:

- Setting up your GitHub and Discord accounts
- Choosing something to work on (good first issues and help wanted)
- The fork → branch → commit → pull request workflow
- Reporting bugs and suggesting enhancements
- Pull request and code review expectations
- The Developer Certificate of Origin (DCO), copyright, and licensing

If you just have a quick question, check the [Besu documentation](https://docs.besu-eth.org/) or ask in the [Besu Discord](https://discord.com/invite/hyperledger). Please don't open an issue to ask a question.
